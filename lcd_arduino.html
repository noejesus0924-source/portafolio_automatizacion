TEMA 02 · PANTALLA LCD I2C CON ARDUINO

Indicador de estado con display LCD 16x2 (I2C)

Este proyecto muestra cómo usar una pantalla LCD 16x2 con módulo I2C para dar retroalimentación visual de un proceso en curso: un mensaje fijo ("CLASIFICANDO...") y un contador de segundos que avanza en tiempo real, mientras el fondo de la pantalla parpadea para indicar que el sistema sigue activo. Es un patrón muy común en automatización: cualquier proceso que tarde varios segundos necesita una forma de decirle al usuario "estoy trabajando" y cuánto tiempo lleva haciéndolo.

Montaje del circuito

El Arduino Uno se conecta al módulo LCD I2C usando solo cuatro cables, gracias a que el módulo I2C reduce las 16 conexiones típicas de un LCD paralelo a solamente 2 líneas de datos:

  1. GND (negro): tierra común entre el Arduino y el módulo LCD.
  2. VCC (rojo): alimentación de 5V tomada del pin 5V del Arduino.
  3. SDA (amarillo): línea de datos I2C, conectada al pin A4 en un Arduino Uno.
  4. SCL (verde): línea de reloj I2C, conectada al pin A5 en un Arduino Uno.
En un Arduino Uno, los pines A4 (SDA) y A5 (SCL) están reservados por hardware para el protocolo I2C. En otras placas (Mega, Nano, ESP32) estos pines pueden cambiar, así que conviene revisar el diagrama de pines antes de conectar el módulo.

Materiales necesarios

Componente Función en el proyecto
Arduino Uno Microcontrolador que ejecuta el sketch y gobierna la pantalla.
Pantalla LCD 16x2 Display de cristal líquido de 16 columnas por 2 filas donde se muestra el texto.
Módulo adaptador I2C (PCF8574) Va soldado detrás del LCD; convierte las 16 conexiones paralelas del display en solo 2 líneas (SDA/SCL), y añade un potenciómetro para ajustar el contraste.
Cables Dupont (macho-hembra) Conectan los 4 pines del módulo I2C (GND, VCC, SDA, SCL) con el Arduino.
Cable USB Alimenta el Arduino y permite cargar el programa desde la computadora.
Librería Adafruit_LiquidCrystal Software: traduce las instrucciones del sketch (print, setCursor, setBacklight) en comandos I2C reales para el controlador del LCD.

Código del sketch

El programa inicializa la pantalla, imprime un mensaje fijo y luego, en el ciclo principal, actualiza un contador y hace parpadear la luz de fondo (backlight) cada medio segundo:

SKETCH.INO
// C++ code
//
#include <Adafruit_LiquidCrystal.h>

int seconds = 0;

Adafruit_LiquidCrystal lcd_1(0);

void setup()
{
  lcd_1.begin(16, 2);

    lcd_1.print("CLASIFICANDO...");
}

void loop()
{
  lcd_1.setCursor(0, 1);
  lcd_1.print(seconds);
  lcd_1.setBacklight(1);
  delay(500); // Wait for 500 millisecond(s)
  lcd_1.setBacklight(0);
  delay(500); // Wait for 500 millisecond(s)
  seconds += 1;
}

Cómo funciona el código, línea por línea

#include <Adafruit_LiquidCrystal.h>
Carga la librería que sabe "hablar" el protocolo I2C con el controlador del LCD. Sin ella, el Arduino no tendría forma de traducir print() o setCursor() en señales eléctricas para la pantalla.
int seconds = 0;
Variable global que guarda el número de segundos transcurridos. Al ser global, conserva su valor entre una vuelta del loop() y la siguiente.
Adafruit_LiquidCrystal lcd_1(0);
Crea el objeto que representa la pantalla física. El "0" es la dirección I2C del módulo (las direcciones típicas son 0x00, 0x20 o 0x27 según el fabricante).
setup() → lcd_1.begin(16, 2);
Se ejecuta una sola vez al encender la placa. Le indica a la librería que el display tiene 16 columnas y 2 filas, para que calcule correctamente las posiciones del cursor.
lcd_1.print("CLASIFICANDO...");
Escribe el texto fijo en la primera fila (posición por defecto). Al estar dentro de setup(), se imprime una sola vez y permanece en pantalla.
loop() → lcd_1.setCursor(0, 1);
Mueve el cursor a la columna 0 de la fila 1 (la segunda fila, ya que se cuenta desde 0), justo debajo del mensaje fijo, para no sobrescribirlo.
lcd_1.print(seconds);
Imprime el valor actual del contador en esa posición. Como el contador no se borra entre vueltas, los dígitos antiguos pueden quedar parcialmente visibles si el nuevo número tiene menos cifras (por ejemplo, al pasar de "100" a "99" quedaría un "9" sobrante); en una versión más robusta se añadiría lcd_1.print(" ") o lcd_1.clear() para limpiar ese resto.
setBacklight(1) / delay(500) / setBacklight(0) / delay(500)
Encienden y apagan la luz de fondo del LCD cada 500 milisegundos, generando un parpadeo continuo que indica visualmente que el proceso sigue en marcha.
seconds += 1;
Incrementa el contador en 1 al final de cada vuelta del loop(). Como cada vuelta dura 1 segundo completo (500 ms + 500 ms de delay), el contador avanza aproximadamente un segundo real por unidad.
Este sketch es un ejemplo de lazo abierto: el Arduino no verifica si el proceso de "clasificación" realmente terminó, simplemente cuenta el tiempo transcurrido. En un sistema real, el contador se detendría al recibir una señal de un sensor o de otra parte del programa que confirme que el proceso concluyó.
