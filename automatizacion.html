BANDA TRANSPORTADORA CLASIFICADORA DE OBJETOS POR COLOR

Planeación del proyecto — Automatización con Arduino Mega e Inteligencia Artificial

DESCRIPCIÓN DEL PROCESO ¿En qué consiste el proyecto?

Descripción

El proyecto consiste en automatizar una banda transportadora capaz de identificar y clasificar objetos según su color. Los objetos avanzan por la banda hasta llegar a un sensor que detecta su color. Después, el sistema procesa la información y activa un mecanismo que dirige cada objeto hacia el recipiente correspondiente. De esta manera, se busca realizar automáticamente una tarea que normalmente tendría que hacerse de forma manual, haciendo el proceso más rápido, ordenado y eficiente.

Problema o necesidad

Actualmente, la clasificación de objetos por color puede realizarse de forma manual, lo que requiere tiempo y puede generar errores al momento de separar los objetos. Además, cuando se manejan muchos objetos, el proceso puede volverse lento y poco eficiente. Por esta razón, surge la necesidad de automatizar la clasificación mediante una banda transportadora, utilizando sensores y un microcontrolador para identificar el color de cada objeto y colocarlo en el recipiente correspondiente. El proyecto busca demostrar cómo la automatización y la Inteligencia Artificial pueden facilitar tareas repetitivas, reduciendo el tiempo de trabajo y mejorando la organización y precisión del proceso.

OBJETIVOS General y específicos

Objetivo general

Desarrollar una banda transportadora automatizada que permita identificar y clasificar objetos de diferentes colores de manera rápida y precisa. El sistema utilizará sensores, motores e inteligencia artificial para detectar el color de cada objeto y posteriormente dirigirlo automáticamente hacia el área de clasificación correspondiente, buscando reducir el trabajo manual, mejorar la organización y demostrar la aplicación de la inteligencia artificial en procesos industriales.

Objetivos específicos

1
Diseñar y construir una banda transportadora automatizada que traslade los objetos desde el punto de inicio hasta el área de detección y clasificación, usando un motor DC de 12 V para el movimiento continuo de la banda.
2
Implementar la detección de colores mediante el sensor TCS3200, para identificar el color de cada objeto. La información se envía al Arduino Mega para ser procesada y utilizada en la clasificación.
3
Programar el Arduino Mega para recibir la información del sensor de color, analizarla y determinar hacia qué recipiente debe dirigirse cada objeto.
4
Integrar un servomotor al sistema de clasificación como mecanismo de desvío, para dirigir los objetos hacia el recipiente correspondiente según el color detectado.
5
Realizar pruebas y ajustes al prototipo, verificando que la banda, el sensor, el motor, el servomotor y el Arduino funcionen correctamente en conjunto, logrando una clasificación rápida, ordenada y precisa.

Cómo funciona

El funcionamiento comienza cuando se enciende el sistema y el Arduino Mega inicia el control de los componentes. El motor DC pone en movimiento la banda; el objeto colocado sobre ella se desplaza hasta el sensor TCS3200, que identifica su color y envía la información al Arduino. El Arduino procesa el dato y decide hacia qué recipiente dirigirlo, activando el servomotor correspondiente. Una vez desviado el objeto, el servomotor regresa a su posición inicial y la banda continúa funcionando para el siguiente objeto. El proceso se repite de forma automática mientras el sistema permanezca encendido.

Secuencia paso a paso

Inicio → Encender el sistema → Arduino Mega inicia el programa → Activar motor de la banda → Colocar objeto en la banda → Transportar objeto hacia el sensor → Sensor TCS3200 identifica el color → Arduino procesa la información → ¿Qué color tiene el objeto? → Seleccionar recipiente correspondiente → Activar servomotor → Desviar el objeto hacia el recipiente → Regresar servomotor a su posición inicial → Continuar movimiento de la banda → ¿Hay otro objeto? (Sí → repetir el proceso / No → esperar nuevos objetos) → Fin.

FUNCIONAMIENTO GENERAL Y RESULTADO ESPERADO Visión del proyecto terminado

Funcionamiento general

El funcionamiento general consiste en transportar automáticamente diferentes objetos mediante una banda transportadora hasta una zona de detección. Cuando un objeto llega a esta zona, el sensor TCS3200 identifica su color y transmite la información al Arduino Mega, que analiza los datos y activa el servomotor para clasificar el objeto en el recipiente correspondiente, regresando después a su posición inicial mientras la banda continúa funcionando.

Resultado esperado

Al finalizar el proyecto se espera obtener un prototipo funcional de una banda transportadora automatizada capaz de identificar objetos según su color y dirigirlos hacia diferentes recipientes, reduciendo la intervención humana y demostrando cómo sensores, actuadores y un microcontrolador pueden automatizar actividades repetitivas de forma práctica.

RIESGOS Y SEGURIDAD Prevención
Riesgo Medida preventiva
Cortocircuitos, descargas eléctricas o daños en componentes por conexiones incorrectas. Revisar las conexiones antes de encender el sistema, mantener los cables ordenados y desconectar la alimentación antes de modificarlo.
Riesgos mecánicos: golpes, pellizcos o atrapamientos por la banda, motores y piezas móviles. No acercar las manos a las partes móviles mientras la banda esté funcionando y asegurar correctamente todas las piezas.
Riesgos térmicos: componentes eléctricos o motores que se calientan durante su funcionamiento. Evitar tocar componentes calientes y permitir que el equipo se enfríe antes de manipularlo.
Otros riesgos: tropiezos por cables sueltos o daños por mal uso de herramientas. Mantener el área de trabajo limpia y ordenada, utilizando las herramientas correctamente.

ALGORITMO DE CLASIFICACIÓN DE OBJETOS POR COLOR Pseudocódigo

Inicio

1. Encender el sistema.
2. Inicializar el Arduino Mega.
3. Configurar el sensor de color TCS3200.
4. Configurar el motor de la banda transportadora.
5. Configurar el servomotor.
6. Encender el motor para comenzar a mover la banda.
7. Colocar un objeto sobre la banda transportadora.
8. Esperar a que el objeto llegue al área de detección.
9. Leer el color del objeto mediante el sensor TCS3200.
10. Enviar los datos del sensor al Arduino Mega.
11. Procesar la información recibida.
12. Determinar el color del objeto.
13. Si el objeto corresponde al primer color, mover el servomotor hacia el primer recipiente.
14. Si corresponde a otro color, mover el servomotor hacia el recipiente correspondiente.
15. Permitir que el objeto sea desviado hacia su recipiente.
16. Regresar el servomotor a su posición inicial.
17. Mantener funcionando la banda transportadora.
18. Verificar si hay otro objeto.
19. Si hay otro objeto, repetir el proceso desde el paso 8.
20. Si no hay otro objeto, mantener el sistema en espera.
