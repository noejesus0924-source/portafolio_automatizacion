TEMA 01 · FUNDAMENTOS

Introducción a la Automatización de Procesos Industriales y de Servicios

La automatización es la disciplina que permite que una máquina o un sistema realice una tarea de forma total o parcial sin intervención humana directa, tomando decisiones a partir de información que recibe del entorno. En la industria se usa para fabricar, ensamblar o transportar productos; en los servicios, para gestionar procesos como el control de accesos, la climatización de un edificio, la facturación o el monitoreo remoto de equipos.

Detrás de cualquier proceso automatizado —desde una línea de embotellado hasta un termostato inteligente— existe la misma idea central: medir, decidir y actuar. Un sensor mide una condición del proceso, un controlador decide qué se debe hacer con esa información, y un actuador ejecuta la acción física correspondiente.

Conceptos clave

Estos son los términos que aparecerán una y otra vez a lo largo del portafolio:

Proceso
Conjunto de operaciones que transforman una entrada en una salida (por ejemplo, materia prima en producto terminado, o una solicitud en un servicio completado).
Variable de proceso
Magnitud física que se mide y se busca mantener bajo control, como temperatura, presión, nivel, velocidad o flujo.
Sensor
Elemento que detecta una variable física y la convierte en una señal que el sistema puede interpretar.
Actuador
Elemento que ejecuta una acción física a partir de una orden del controlador: mover, calentar, abrir, encender.
Controlador
El "cerebro" del sistema. Compara el valor medido contra el valor deseado y calcula la acción necesaria. Puede ser un microcontrolador (como Arduino), un PLC o un programa de software.
Setpoint (punto de consigna)
Valor deseado de una variable de proceso, contra el cual el controlador compara la medición real.
Retroalimentación (feedback)
Información que regresa al controlador sobre el resultado real de su acción, permitiendo corregir el rumbo.
Lazo abierto vs. lazo cerrado
Un sistema en lazo abierto ejecuta una acción sin verificar el resultado; uno en lazo cerrado usa retroalimentación para ajustarse continuamente.
PLC (Controlador Lógico Programable)
Computadora industrial robusta, diseñada para controlar maquinaria y procesos en entornos exigentes.
HMI / SCADA
La HMI (interfaz humano-máquina) permite a una persona visualizar y operar el proceso; SCADA amplía esa supervisión a un sistema completo y distribuido.

El entorno Arduino

Arduino es una plataforma de hardware y software libre, pensada para que cualquier persona pueda construir prototipos de automatización sin necesidad de electrónica avanzada. Una placa Arduino funciona como un pequeño controlador: lee señales de sensores a través de sus pines de entrada, ejecuta un programa (llamado sketch) escrito en un lenguaje basado en C/C++, y envía órdenes a actuadores mediante sus pines de salida.

Su popularidad en proyectos de automatización industrial y de servicios se debe a tres factores: bajo costo, una comunidad enorme de soporte y documentación, y una gran cantidad de módulos compatibles (relés, motores, pantallas, sensores de temperatura, humedad, distancia, etc.) que se conectan de forma sencilla.

Un flujo típico en Arduino: el sensor entrega una señal → el microcontrolador la lee y la compara con una condición programada → si se cumple, activa un actuador (relé, motor, LED, válvula) → opcionalmente, envía el dato a la nube para su registro o visualización remota.

De Arduino al IoT

El Internet de las Cosas (IoT, por sus siglas en inglés) consiste en conectar objetos físicos a internet para que puedan enviar datos, recibir órdenes o ser monitoreados a distancia. Cuando un proyecto de Arduino incorpora conectividad —normalmente mediante un módulo WiFi como el ESP8266 o el ESP32— el sistema deja de ser un dispositivo aislado y se convierte en un nodo de una red más amplia.

En automatización industrial, a esta combinación se le conoce como IIoT (IoT Industrial). Permite, por ejemplo, revisar desde un celular la temperatura de una cámara de refrigeración, recibir una alerta cuando un tanque está por desbordarse, o registrar en la nube el consumo eléctrico de una línea de producción para analizarlo después.

  1. Captura: un sensor conectado a Arduino o a un módulo ESP mide una variable física.
  2. Procesamiento local: el microcontrolador decide si debe actuar de inmediato (por ejemplo, encender una alarma).
  3. Transmisión: el dato se envía por WiFi usando un protocolo ligero como MQTT o solicitudes HTTP.
  4. Nube y visualización: plataformas como ThingSpeak, Blynk o Node-RED reciben, almacenan y muestran la información en tableros accesibles desde cualquier lugar.
  5. Acción remota (opcional): desde esos mismos tableros, una persona puede enviar una orden de regreso al dispositivo, cerrando el ciclo.

En conjunto, estos fundamentos —proceso, sensor, actuador, controlador y retroalimentación— junto con herramientas accesibles como Arduino y los protocolos del IoT, forman la base sobre la que se construyen los demás temas de este portafolio.
