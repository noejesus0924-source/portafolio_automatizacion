TEMA · CONTROL DE SERVOMOTORES

🦾 Control de Servomotores 🦾

🖼️ Diagrama del circuito

Señal (PWM) → pines digitales Alimentación → 5V Tierra → GND

En esta imagen se ve un Arduino Uno actuando como controlador de tres servomotores, uno de los actuadores más usados en proyectos de automatización. Cada servo tiene tres cables, y ese es justo el patrón que hay que aprender a leer en cualquier diagrama de este tipo:

  • Cable naranja (señal): sale de un pin digital con PWM (marcado con "~", por ejemplo ~11, ~10 o ~9) hacia el cable de señal del servo. Es la línea por la que el Arduino le "dice" al motor en qué ángulo debe colocarse.
  • Cable rojo (alimentación): conecta el pin 5V del Arduino con el cable de poder del servo, dándole la energía necesaria para mover el engrane interno.
  • Cable negro (tierra/GND): conecta el GND del Arduino con el GND del servo, cerrando el circuito eléctrico. Sin esta conexión común, la señal de los cables naranjas no tendría una referencia y el motor no respondería bien.

Como los tres servos comparten los mismos pines de 5V y GND, sus cables rojos y negros parten del mismo grupo de pines de la sección de alimentación del Arduino, mientras que cada cable naranja va a un pin digital distinto, para que el programa pueda mover cada servo de forma independiente (por ejemplo, con la librería Servo.h y una instancia distinta para cada motor).

⚙️ ¿Qué es un servomotor y por qué es un actuador?

Retomando el vocabulario visto en Conceptos Clave, el servomotor es un actuador: convierte una señal eléctrica (el pulso PWM que envía el Arduino) en un movimiento físico preciso, generalmente girando su eje a un ángulo específico entre 0° y 180°. A diferencia de un motor DC normal, el servo trae internamente un pequeño circuito de control y un potenciómetro que le permiten "saber" en qué posición está y corregirse solo, lo cual es justamente el principio de retroalimentación aplicado dentro de una sola pieza.

🔄 Este circuito dentro del ciclo de automatización

Etapa del ciclo En este circuito
Procesar El Arduino Uno ejecuta el programa y decide qué ángulo debe tomar cada servomotor.
Actuar Cada servomotor recibe su pulso PWM por el cable naranja y gira su eje a la posición indicada.
Alimentación Los cables rojo y negro entregan la energía (5V y GND) que necesitan los tres servos para funcionar.

Este montaje con tres servomotores es una base muy común para proyectos como brazos robóticos simples, sistemas de apertura/cierre (compuertas, persianas) o paneles que se orientan automáticamente, todos ejemplos de automatización de procesos con actuadores mecánicos controlados por un microcontrolador.

💻 Código de Arduino para este circuito

Este es el sketch que mueve los tres servomotores del diagrama de forma sincronizada, barriendo de 0° a 180° y de regreso, de manera continua:

SKETCH.INO
#include <Servo.h>

Servo servo1;
Servo servo2;
Servo servo3;

void setup() {
  servo1.attach(11);
  servo2.attach(12);
  servo3.attach(13);

  // Posición inicial
  servo1.write(90);
  servo2.write(180);
  servo3.write(0);
  delay(1000);
}

void loop() {
  // De 0° a 180°
  for (int angulo = 0; angulo <= 180; angulo++) {
    servo1.write(angulo);
    servo2.write(angulo);
    servo3.write(angulo);
    delay(15);
  }

  // De 180° a 0°
  for (int angulo = 180; angulo >= 0; angulo--) {
    servo1.write(angulo);
    servo2.write(angulo);
    servo3.write(angulo);
    delay(15);
  }
}
  • Librería Servo.h: incluye las funciones necesarias para generar la señal PWM que entienden los servomotores.
  • attach(pin): asocia cada objeto Servo con el pin digital donde está conectado su cable naranja (11, 12 y 13).
  • setup(): antes de empezar el barrido, coloca cada servo en una posición inicial distinta (90°, 180° y 0°) y espera un segundo.
  • loop(): mueve los tres servos al mismo tiempo, grado por grado, primero subiendo de 0° a 180° y luego bajando de 180° a 0°, con una pequeña pausa de 15 ms entre cada paso para que el movimiento se vea suave.
